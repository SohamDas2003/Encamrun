# Encamrun

A high-performance digital marketing agency web application and interactive growth diagnostic platform for [Encamrun](https://encamrun.co.in).

## Features

- **Full-Funnel Services Showcase**: Interactive presentation of SEO, PPC, Performance Creative, CRO, and Lifecycle solutions.
- **Client Case Studies**: Real-world metrics and revenue acceleration breakdowns.
- **Growth Audit Tool**: Diagnostic assessment for calculating channel leakage and growth opportunities.
- **Interactive ROAS & Ad Spend Calculator**: Dynamic financial modeling tool for marketing budgets.
- **Centralized Configuration**: Configured entirely via `src/lib/siteConfig.ts` for unified brand variables, pricing, domain, and contact details.

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm

### Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the local development server:
   ```bash
   npm run dev
   ```

3. Open your browser and navigate to `http://localhost:3000`.

### Building for Production

To build the production bundle:
```bash
npm run build
```

To preview the production build locally:
```bash
npm run preview
```
